NodeSpark Wisp

A pocket-sized physical device family that gives NodeSparkHub a real display, speaker, microphone, touch controls, and workflow interface for live automation demos.

Hub linked

Why it matters

NodeSparkHub becomes more than an app screen.

Wisp connects Hub workflows to physical output. It can show workflow status, request approvals, display QR codes, run favorites from a button or touch screen, play sound, and bridge mobile demos through NodeSpark on iPhone.

What it can do

A compact showcase device for automation.

01

Live Hub Display

Show messages, rich cards, progress, alerts, QR codes, dashboards, and branded status screens.

02

Workflow Control

Run selected NodeSparkHub workflows from the hardware button or direct Hub commands.

03

Approvals

Ask for a physical approve or reject decision and send the result back into the workflow.

04

Voice Input

Record short commands and route transcripts into Hub workflows using OpenAI, Vosk, or text-only mode.

05

Speech And Sound

Speak Hub responses through the onboard speaker and play startup, success, and error chimes.

06

Mobile Bridge

Optionally connect NodeSpark on iPhone over Bluetooth LE for travel demos and direct Wisp commands.

Hardware

Two physical builds: Whisplay and ESP32-S3 Touch.

Start with the OpenClaw-style Raspberry Pi Whisplay stack, or build the lower-cost ESP32-S3 touch version with a 2.8-inch ILI9341 display.

Whisplay Wisp

  • Raspberry Pi Zero 2 W
  • PiSugar Whisplay HAT with 1.69-inch LCD
  • Whisplay speaker, microphone, RGB LED, and button
  • PiSugar battery pack

ESP32-S3 Wisp Touch

  • ESP32-S3 N16R8 USB-C board
  • ILI9341 2.8-inch SPI TFT touch display
  • MAX98357 I2S amplifier and speaker
  • INMP441 I2S microphone

Install

Flash the Wisp image, or install manually.

1. Flash the Wisp image

Raspberry Pi Imager -> Use custom
Choose nodespark-wisp.img.xz
Set Wi-Fi + user settings
Flash microSD

2. Pair with NodeSparkHub

Open Hub Server -> Devices
Generate pairing code
Pair Wisp from SSH or QR/setup screen

3. Build the image

bash scripts/build_pi_image.sh

Manual Pi Install

git clone https://github.com/synryzen/nodespark-wisp.git
cd nodespark-wisp
bash scripts/install_pi.sh

ESP32-S3 Touch Build

cp firmware/esp32-s3-wisp/nodespark_wisp_esp32/config.example.h \
  firmware/esp32-s3-wisp/nodespark_wisp_esp32/config.h
bash scripts/build_esp32_s3.sh

NodeSparkHub All Access

The device is full-featured. Hub operation requires an active subscription.

Wisp is not split into separate locked device tiers. The subscription powers the NodeSparkHub runtime behind pairing, command routing, workflow execution, automation history, and iPhone Mobile Bridge forwarding.
