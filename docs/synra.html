NodeSpark Synra

Synra is a Jetson-powered on-screen AI companion for NodeSparkHub: an original adult anime-style assistant who speaks, reacts, shows workflow state, and turns Hub automation into a living monitor presence.

View Synra source Back to Wisp

What it is

Not a replacement OS. A normal Jetson app.

Synra runs on top of the existing Ubuntu install on the NVIDIA Jetson Orin Nano. The Python daemon exposes a local API and serves a full-screen browser monitor UI, so the Jetson can still be used like a normal development machine.

Avatar Presence

A full-screen monitor companion with idle, listening, thinking, speaking, workflow, success, approval, warning, and error states.

Hub Connected

Synra follows the same device pattern as Wisp: pair, check in, poll commands, run workflows, ask the assistant, and acknowledge results.

Jetson Ready

The Jetson can become the local body for voice, camera awareness, local models, and the animated monitor UI while NodeSparkHub remains the workflow brain.
