NodeSpark Wisp

A pocket-sized Raspberry Pi device that gives NodeSparkHub a real display, speaker, microphone, RGB light, and hardware button for live automation demos.

View on GitHub Build one
Hub linked

Why it matters

NodeSparkHub becomes more than an app screen.

Wisp connects Hub workflows to physical output. It can show workflow status, speak responses, request approvals, display QR codes, run favorites from a button, and bridge mobile demos through NodeSpark on iPhone.

What it can do

A compact showcase device for automation.

01

Live Hub Display

Show messages, rich cards, progress, alerts, QR codes, dashboards, and branded status screens.

02

Workflow Control

Run selected NodeSparkHub workflows from the hardware button or direct Hub commands.

03

Approvals

Ask for a physical approve or reject decision and send the result back into the workflow.

04

Voice Input

Record short commands and route transcripts into Hub workflows using OpenAI, Vosk, or text-only mode.

05

Speech And Sound

Speak Hub responses through the onboard speaker and play startup, success, and error chimes.

06

Mobile Bridge

Optionally connect NodeSpark on iPhone over Bluetooth LE for travel demos and direct Wisp commands.

Hardware

Built for the OpenClaw-style Whisplay stack.

The project targets the same physical hardware style used by DIY OpenClaw assistants. OpenClaw is not required; this is NodeSparkHub companion software.

  • Raspberry Pi Zero 2 W
  • PiSugar Whisplay HAT with 1.69-inch LCD
  • Whisplay speaker, microphone, RGB LED, and button
  • PiSugar battery pack
  • MicroSD card, 16 GB or larger recommended
  • Wi-Fi reachable by the Mac running NodeSparkHub

Install

Clone, install, pair, and start the service.

1. Install on the Pi

git clone https://github.com/synryzen/nodespark-wisp.git
cd nodespark-wisp
bash scripts/install_pi.sh

2. Pair with NodeSparkHub

/opt/nodespark-wisp/scripts/pair_device.sh 123456

3. Start the service

sudo systemctl enable --now nodespark-wisp
journalctl -u nodespark-wisp -f

NodeSparkHub All Access

The device is full-featured. Hub operation requires an active subscription.

Wisp is not split into separate locked device tiers. The subscription powers the NodeSparkHub runtime behind pairing, command routing, workflow execution, automation history, and iPhone Mobile Bridge forwarding.
